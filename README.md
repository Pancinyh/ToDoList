# ToDoList
Projeto de lista de tarefas desenvolvido em Python

## Funcionalidades
- Adicionar tarefa
- Remover tarefa
- Listar tarefas
- Salvar tarefas em arquivo
- Salvar cadastro em arquivo
- Junta suas tarefas com seu login, assim cada E-mail possui seu próprio controle de tarefas.

## Tecnologias
- Python 3
